## 重点证据

- UPDATE 多列赋值读取原行，先完成全部计算与编码校验，再写入；后续行除零、越界和总记录超限不会改动前面的行。
- 变长 UPDATE 在容量为 1 的页缓存下可跨页迁移，50 行更新计数和重启后记录均正确；插入失败不会预先删除旧记录。
- 查询覆盖隐藏排序列、中文、多键、别名冲突、自连接、三表连接、重复匹配、五种聚合、分组合法性和 HAVING 三值逻辑。
- 原计划与优化计划对普通结果、空表、短路、除零、宽整数行为保持一致。
- 旧库夹具由 `799ec26` 的真实代码生成，以压缩内容和 SHA-256 存于 `tests/fixtures/v1_database.json`，兼容测试不依赖运行时 Git。
